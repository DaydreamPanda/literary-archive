# 章节 Tag 可选继承 + 隐藏全书资料

此补丁适用于 DaydreamPanda/literary-archive 当前版本，**无须 SQL**。

## 上传到 GitHub

请保留目录结构，将下列四个代码文件上传/覆盖：

- `chapter-tags-editor.js`（仓库根目录）
- `archive-enhancements.js`（仓库根目录）
- `functions/api/archive-chapter-tags.js`
- `functions/api/archive-book-extras.js`

在 GitHub 提交后，等 Cloudflare Pages 部署成功，强制刷新网页。

## 使用

1. 打开任意章节的编辑页面。
2. 右栏的「BOOK DETAILS / 全书资料」板块不再展示；右栏保留「章节设置」「本节 Tag」。
3. 书籍 Tag 会默认勾选，可逐个取消。也可增加其他 Tag。
4. 点击「保存本节 Tag」。这会保存当前章节的完整标签选择，不会修改整本书的 Tag。
5. 新建章节时可提前调整勾选，先发布正文，再点击「保存本节 Tag」。

## 兼容和安全

- 从未设置过独立 Tag 的章节继续默认继承全书 Tag。
- 老版存储为 JSON 数组的「额外 Tag」仍可读取，保持原有叠加关系。首次保存新的章节选择后会转换为新版显式模式。
- 可以取消全部 Tag，显式存储空列表；随后即使书籍新增 Tag，也不会自动强制加回该章节。
- 阅读页会显示章节实际选中的 Tag；系列目录卡片也会按章节当前选择显示。
- 只修改前端脚本和读取/保存标签的 API，不修改正文、封面、评论、点赞、已发布章节。
- 原先「全书资料」部分的 HTML 元素仍留在页面中但被隐藏。这是为了兼容 `chapter-editor.js` 的旧监听器，避免直接移除后报错。

## 建议验收

- 选一本有两个 Tag 的书，打开某章，取消一个并保存；刷新编辑器，确认状态保留。
- 打开该章阅读页，确认只显示勾选的 Tag。
- 打开同书另一章，确认没有被牵连。
- 新建测试章节，检查默认勾选。
