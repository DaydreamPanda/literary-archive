# 文学档案馆：手动目录管理补丁

上传压缩包内以下文件到 GitHub 仓库根目录，保持目录结构：

- `archive-structure.html`（覆盖旧目录管理页）
- `archive-structure-admin.js`（覆盖旧目录管理脚本）
- `pixiv-import.html`（覆盖旧 Pixiv 导入页，取消自动分组）
- `functions/api/admin/archive-structure.js`（覆盖原目录保存接口，同时保存真实阅读顺序）

Cloudflare Pages 重新部署成功后，登录后台，打开 `/archive-structure.html`。

1. 选择作品。
2. 勾选需要合并的篇目，在「大章标题」填写如 `第一回`，点「合并所选」。
3. 单节章节保持各自的大章名称，会直接进入阅读页。
4. 想拆开已合并的节：勾选后点「拆分所选」，或手工修改每行的「所属大章」。
5. 拖动 ☰ 或用 ↑ ↓ 排序。
6. 点击「保存目录与顺序」。顺序会同时应用到章节目录及上一篇、下一篇。

说明：
- 合并只改变目录关系，原正文、封面、点赞和评论不变。
- 导入器不再自动判断上中下，仍支持 Pixiv EPUB 作品封面、章节封面、Tag。
- 如果后台刚新增了篇目，请先刷新目录管理页再保存，避免覆盖其他人已保存的更改。
- 建议在后台先导出全站 JSON 备份。
