白日做梦熊猫头的文学档案馆 · 章节写作编辑器 v2

重要：这个压缩包是覆盖补丁，只替换同名文件并新增 4 个 API 文件。不要删除 GitHub 原项目里的其他文件，也不要上传 ZIP 本身。

一、部署
1. 备份 GitHub 仓库：Code → Download ZIP（你此前已经备份过，也可以再次备份）。
2. 解压此压缩包，在解压目录内全选所有文件和 functions 文件夹。
3. GitHub 打开 DaydreamPanda/literary-archive，main 分支 → Add file → Upload files。
4. 拖入这些文件，保持 functions/api/admin 等原始目录结构。
5. 直接提交到 main，Cloudflare Pages 自动开始构建/部署。等待绿色成功。
6. 之前已经在 admin.html 添加过 /admin-editor-link.js，因此不用再次修改 admin.html。

二、新增和更新功能
- 作者后台原来的“添加章节”按钮：先选择目标书，点击按钮后转到 /chapter-editor.html?book=书ID。旧输入框里的临时标题与正文会带到新编辑器。
- 章节列表“编辑”按钮：跳到 /chapter-editor.html?id=章节ID，不再弹出旧式的 prompt。
- 左侧：章节标题、正文、实时字数、B/I、H2/H3、引用、撤销、重做、排版预览、保存以及打开阅读页。
- 右侧“章节设置”：章节简介、独立章节封面，可选。未设置章节封面时继续显示作品封面。
- 右侧“作品设置”：整本书的封面、简介和 Tags。作品 Tags 会影响整本书，而不会只影响单节。
- 独立图片将以 D1 BLOB 保存，单张图片限制 1 MB。较大图片会由浏览器先尝试压缩。
- Markdown 格式：**加粗**，*斜体*，## 标题，### 小标题，> 引用。文本默认安全转义，已有纯文本章节继续正常显示。
- 新版添加了三个 Pages Functions 接口：archive-chapter-meta（公开读/管理员写），archive-chapter-cover（公开查看），以及两者对应的管理员 API。复用既有 D1 和 site_settings，不需要另外创建数据表。

三、建议测试顺序（先用现有“熊猫头测试小说”）
1. 后台创建一节新章节，确认跳入独立编辑页，输入标题和正文并发布。
2. 在正文输入 **加粗**、## 小标题、> 引用，点击“预览排版”，再保存并查看阅读页面。
3. 右侧修改章节简介、作品简介和 Tags，分别保存，刷新阅读页/书籍页验证。
4. 上传一张小于 1 MB 的封面；如果是章节封面，保存后阅读页顶部应该显示该封面。
5. 确认旧章节正文和匿名评论、点赞仍正常显示。

四、注意
- “发布章节”与“保存章节设置”是两个不同保存入口。作品资料另有自己的保存按钮，避免改正文时意外改整本书。
- 内容直接保存到你的 Cloudflare D1；改动完成后可在原管理后台导出全文备份。
- 此补丁经过静态语法和本地浏览器模拟测试，尚未在你的 Cloudflare 账号上进行真实接口联调。若遇到报错，请保留原内容并把错误提示发来。
